# Контур — калькулятор помещения

Введите длину, ширину и высоту в метрах. Площадь пола и объём обновляются автоматически. Можно вводить дробные числа с запятой или точкой. Подходит для прямоугольной комнаты.

## Запуск

В папке проекта выполните `npm start` (нужен Python 3). Откройте сайт на порту 3000. Установка зависимостей не требуется. Подойдёт и любой сервер статических файлов.

`npm test` проверяет формулы и обработку неверного ввода (Node.js 18+).

Площадь = длина × ширина. Объём = длина × ширина × высота. Результаты округляются до четырёх знаков после запятой. Данные не отправляются на сервер. Google Fonts используется для шрифта, без интернета работает системный шрифт.
