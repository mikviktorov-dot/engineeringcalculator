# Контур 2.0 — калькулятор помещения

Сохранён исходный прямоугольный калькулятор. Новый режим «Произвольная форма» строит ортогональный план с нишами и выступами.

## Управление

1. Выберите «Произвольная форма».
2. Нажимайте на сетку последовательно: шаг 0,25 м, направление автоматически горизонтальное или вертикальное.
3. Последнюю точку расположите на одной горизонтали или вертикали с первой. Нажмите «Замкнуть контур» либо первую точку.
4. Для изменения геометрии тяните угол. Соседние углы перемещаются вместе с ним, сохраняя прямые углы. Неверное положение отклоняется.
5. Для точных размеров измените нужные поля стен и нажмите «Применить размеры». Суммы длин вправо/влево и вверх/вниз должны совпасть. Например, у прямоугольника меняйте противоположные стены вместе.
6. Масштабируйте кнопками + / − или двумя пальцами. «Перемещать план» включает сдвиг сетки. «План целиком» возвращает весь контур в кадр.
7. «Отменить» открывает замкнутый контур, затем удаляет последнюю точку. «Начать заново» очищает план.

Ввод размеров поддерживает запятую и точку, до трёх знаков после запятой в произвольном режиме. Пока размеры не применены или некорректны, результаты скрыты. Переключение режимов сохраняет черновик плана в текущей вкладке.

## Формулы и ограничения

- Площадь пола: модуль половины суммы векторных произведений последовательных вершин (формула Гаусса).
- Периметр: сумма длин стен.
- Площадь стен: периметр × высота, без вычета дверей и окон.
- Объём: площадь пола × высота.
- Масштаб экрана не участвует в расчётах. Округление результатов — до четырёх знаков.
- Только один простой замкнутый ортогональный многоугольник, без отверстий. Самопересечения, касания несоседних стен, нулевые стены, развороты и диагонали запрещены.
- При перетаскивании шаг 0,25 м. Точные дробные размеры задаются в полях.
- Числовые размеры проверяются совместно; автоматического решения системы произвольных ограничений нет.
- Нет сохранения между перезагрузками, экспорта, дверей и окон. Исходный визуальный стиль сохранён.
- Кнопки и зоны захвата углов рассчитаны на касание (минимум 44–48 CSS px); на тесном плане сначала увеличьте масштаб.
- На физическом iPhone/Android требуется отдельная проверка жестов и читаемости подписей. На коротких стенах подписи могут пересекаться.

## Запуск и тестирование

Node.js 18+ и Python 3. Установка зависимостей не нужна.

```sh
npm start
npm test
node --check app.js
node --check editor.js
node --check geometry.js
```

Откройте порт 3000. Тесты взаимодействий используют небольшой DOM/SVG-адаптер (это не проверка браузерной вёрстки): построение, замыкание при pointer capture, несовместимые размеры, отмена жеста, перенос угла и масштабирование. Геометрические тесты покрывают прямоугольник, Г-образную комнату, нишу, выступ, дробные размеры, порядок обхода, смещение координат, неправильные контуры, изменение размеров и перенос углов.

Данные обрабатываются в браузере и не отправляются на сервер. Google Fonts используется для шрифта; без сети работает системный шрифт. Эта ветка не содержит автоматической публикации.
